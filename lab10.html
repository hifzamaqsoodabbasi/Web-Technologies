How This System Works

  • Constructor Function: Student objects are created using a constructor function
  • CRUD Operations: Create, Read, Update, Delete student records
  • Dynamic Updates: The display updates immediately when records change
  • Additional Features: Search, sort, highlight top performers, statistics
  • Modular Design: Each function handles a specific operation
// Constructor function for Student objects
function Student(id, name, rollNumber, cgpa, course) {
  this.id = id;
  this.name = name;
  this.rollNumber = rollNumber;
  this.cgpa = parseFloat(cgpa);
  this.course = course;
  this.getStatus = function() {
    if (this.cgpa >= 8.0) return "Excellent";
    if (this.cgpa >= 6.0) return "Good";
    if (this.cgpa >= 4.0) return "Average";
    return "Needs Improvement";
  };
}

Reflective Learning

This experiment fundamentally transformed my understanding of object-oriented programming in JavaScript through practical implementation of constructor functions and modular design. By creating the Student constructor function, I moved beyond theoretical concepts to witness how blueprint functions enable consistent object creation with encapsulated properties and methods—each student object became a self-contained entity with its own getStatus() method, demonstrating how data and behavior can be bundled together. The modular approach to CRUD operations revealed the power of separation of concerns: addStudent() handled object creation, displayStudents() managed presentation logic, updateStudent() focused on data modification, and deleteStudent() addressed removal—each function with a single, clear responsibility that made debugging and testing remarkably straightforward. Through implementing this system, I realized that constructor functions aren't just syntactic sugar but essential patterns for scalable applications, while modular design proved crucial for maintainability as I could modify the search algorithm without touching form validation logic or update statistics calculation without affecting the display rendering. This hands-on experience illuminated how professional JavaScript applications are structured, where clean separation between data models (Student objects), business logic (CRUD operations), and presentation layer (DOM manipulation) creates robust, adaptable systems that can evolve without becoming entangled—ultimately demonstrating how object-oriented principles combined with modular architecture form the foundation of sustainable, real-world software development.
